中小学学科学习网站 · 架构与内容模型

设计文档 v1.3 · 以学科为栏目 · 学科内按上册/下册组织学习空间 · 整年级内容导入后自动匹配年级与上下册 · 标签为枢纽 · 文章为最小单位

一、信息架构总览（v1.3 修订）

导航以「学科栏目」为主轴：首页呈现内容流 → 进入某一学科栏目 → 该栏目下是上册 / 下册的学习空间（再按内容类型 / 单元组织）。年级是学习语境：内容由整年级批量导入后自动打上年级与上下册标签，按学生所属年级拉取。

主线：首页（内容）→ 学科栏目 → 学习空间（上/下册）→ 文章 → 练习。年级作为语境贯穿始终；标签专题 / 搜索 / 个人中心为全局入口。

二、学科栏目 × 内容类型（栏目下的子分类）

每个学科栏目内置自己的内容类型子栏目，互不通用；数学的应用题 / 计算题会按年龄段（年级）呈现不同难度。

学科栏目内容类型（子栏目）
语文成语 · 诗词 · 文言 · 作文 · 故事 · 阅读 · 课文
数学应用题 · 计算题（按年龄段/年级区分难度）
英语单词 · 听力 · 短语 · 句子 · 阅读 · 课文背诵
科学 规划中实验 · 知识 …（可含 化学 / 地理 作为子方向）
化学 规划中知识 · 计算 …
地理 规划中知识 · 读图 …
历史 规划中史实 · 人物 · 阅读（人文类）
栏目采用「开放注册」思路：先上 语文 / 数学 / 英语，后续通过配置即可新增 科学（化学/地理）/ 历史 等栏目，无需改结构。

三、首页原型：内容为主 · 今日学习

首页第一屏直接呈现内容（今日任务 / 继续学习 / 热门标签），按学生所在年级自动生成。年级在「个人中心」设置，作为全局语境。

四、学科栏目页（以学科为栏目 · 可点击体验）

点学科栏目进入其学习空间（默认当前年级：五年级）。学习空间内按上册 / 下册切换，册内按内容类型 / 单元组织。

说明：语文 / 数学 / 英语 已预置五年级示例内容；科学 / 化学 / 地理 / 历史 为规划中栏目（点击看占位说明）。

五、结构枢纽：标签系统（全站中枢）

目录树是"刚性"的，标签是"柔性"的。文章打上多类标签后，天然产生交叉；导航、筛选、聚合全部由标签驱动。年级与上下册本身也是标签维度。

一篇"分数加法应用题"携带年级/学科/册/类型/知识点/难度多标签 → 同时出现在 五年级·数学·下册、#应用题 专题、#分数 知识点、首页今日任务中。

六、内容模型：文章（最小内容单位）

所有内容统一为"文章"对象，靠字段与标签区分类型。练习类（应用题 / 计算题 / 听力等）必须含答案与解析，才能在线判分。

字段分组字段说明 / 示例
基础信息title文章标题，如"分数加法应用题"
基础信息grade年级（由整年级导入自动匹配，如 五年级）
基础信息subject学科栏目（语文/数学/英语/科学/历史…）
基础信息volume册别：上册 / 下册（由导入自动匹配）
基础信息unit单元 / 章节：如"第三单元""第五单元"
基础信息type内容类型（栏目子类）：语文=成语/诗词/文言/作文/故事/阅读/课文；数学=应用题/计算题；英语=单词/听力/短语/句子/阅读/课文背诵
基础信息difficulty难度：基础 / 提高 / 易错，或 ★ 评级（同类型跨年级区分难度）
标签区tags知识点等额外标签，如 #分数 #唐诗 #牛顿定律
内容区body正文，支持富文本、公式（LaTeX）、图片、音视频
练习区answer / solution答案与解析；练习类（应用题/计算题/听力等）必填，用于判分
状态status草稿 / 已发布
建议存储为 Markdown/MDX + front-matter。内容定位路径：学科栏目 → 上/下册 →（单元）→ 内容类型 → 文章；年级作为语境标签贯穿。

七、批量导入：整年级内容 → 自动匹配年级与上下册

运营在后台选择一个年级并上传整批内容（文档 / Excel / Markdown 文件夹），系统自动判定并打标，无需逐篇手工分栏。

步骤说明
① 选定年级如「五年级」，批量内容整体归属该年级
② 上传整批内容按学科目录组织：语文/、数学/、英语/…，或直接一个文件夹
③ 自动识别册与单元依据文件名 / 章节标题中的「上册/下册」及「第X单元」字样，自动写 volume、unit 字段
④ 自动归类内容类型依据子目录或关键词（如「诗词」「应用题」「单词」）匹配到对应栏目子类 type
⑤ 人工校正（可选）识别不确定的内容可在后台批量校正标签后再发布
⑥ 自动归位导入后内容按 学科栏目 → 上/下册 → 内容类型 自动落位；首页今日学习按学生年级拉取
年级与上下册是导入阶段确定的硬属性；内容类型与知识点是标签，保持灵活可改。这样"整年级一次性导入、后续按标签自由组合"。

八、页面与功能清单

围绕"今日学什么 → 进哪个学科 → 练习 → 沉淀"的闭环设计页面。

页面核心功能
首页内容为主：今日学习任务流、继续学习（断点续学）、每日推荐、热门标签；按学生年级自动生成
学科栏目页以学科为主轴的分栏导航（语文/数学/英语/…）；点栏目进入学习空间
学习空间某学科某年级的内容页：上册 / 下册切换，册内按内容类型 / 单元组织 + 标签筛选
文章详情页正文展示 + 标签 + 收藏 / 分享 + 相关推荐
练习模式应用题 / 计算题 / 听力等在线作答、即时判分、查看解析、记入错题本
个人中心设置所属年级（全局语境）、收藏、错题本、学习进度 / 知识点掌握度
搜索全文检索 + 标签联想补全
聚合专题页由单个标签或标签组合自动生成的列表页（如"#应用题 全集""#唐诗"）
后台导入选定年级 → 上传整批内容 → 自动匹配年级/上下册/类型 → 校正发布
